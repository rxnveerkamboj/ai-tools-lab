# ai-tools-lab

## 1. Project Description

**ai-tools-lab** is a small Python project created for the AI Tools Lab assignment. It contains a simple hello program, a bubble sort implementation, and a set of beginner-friendly utility functions. The code uses only core Python and does not require external libraries.

## 2. Features

- **Hello program** (`hello.py`): A basic Python script to check that the setup works.
- **Bubble sort** (`sorting.py`): Sorts a list of numbers using the bubble sort algorithm.
- **Utility functions** (`utils.py`):
  - `is_palindrome(s)`: Checks whether a string is a palindrome.
  - `count_words(text)`: Counts the number of words in a text.
  - `celsius_to_fahrenheit(c)`: Converts a temperature from Celsius to Fahrenheit.
